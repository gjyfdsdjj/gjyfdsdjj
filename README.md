# 안녕하세요, 김도림입니다.

사용자 화면과 데이터를 연결하고, 서비스 기능이 실제로 동작하는 과정을 구현하는 데 관심이 있습니다.

Kotlin으로 채용 관리 화면과 DB를 연결하고, Java·Spring Boot로 채팅과 매물 비교 API를 구현했습니다. 현재는 **FEMS-MIDAS** 팀 프로젝트에서 에너지 데이터 처리와 MQTT 기반 장치 제어 기능을 개발하고 있습니다.

## 주요 프로젝트

### FEMS-MIDAS · 진행 중
공장 에너지 모니터링 및 제어 시스템

- **내 기여:** 전력 소비·요금 추정 API, 스케줄러·MQTT 기반 펠티어 제어, 자연어 명령 처리 및 DB·화면 연동
- **사용 기술:** Python, FastAPI, SQLAlchemy, MQTT, Supabase
- [저장소](https://github.com/gjyfdsdjj/FEMS-MIDAS) · [에너지 API 구현 PR](https://github.com/ehdrms3535/FEMS-MIDAS/pull/10) · [장치 제어 연동 PR](https://github.com/ehdrms3535/FEMS-MIDAS/pull/13)

### DodoJob
시니어를 위한 일자리·교육·복지 Android 앱

- **내 기여:** 기업의 지원자 관리 화면, 지원자 상세 조회, 면접 제안 DB 연동, 열람 상태 갱신
- **사용 기술:** Kotlin, Jetpack Compose, Coroutines, StateFlow, Supabase
- [저장소](https://github.com/gjyfdsdjj/dodojob) · [면접 제안 구현 PR](https://github.com/ehdrms3535/dodojob/pull/126) · [열람 상태 갱신 PR](https://github.com/ehdrms3535/dodojob/pull/132)

### Real Estate Hub
부동산 조회·비교·거래 협의 웹 서비스

- **내 기여:** WebSocket/STOMP 채팅, 가중치 기반 매물 비교, 매물·실거래가 조회 API, 이미지 저장 연동
- **사용 기술:** Java, Spring Boot, JPA, PostgreSQL, Supabase Storage
- [저장소](https://github.com/gjyfdsdjj/real-estate-hub-project) · [채팅 구현 PR](https://github.com/pyodolski/real-estate-hub-project/pull/17) · [매물 비교 구현 PR](https://github.com/pyodolski/real-estate-hub-project/pull/23)
